# 设置

打开方式：点击主窗口标题栏左侧的服务按钮。

设置窗口采用左侧导航 + 右侧内容区，左侧为两级目录（一级分组，二级页面）。当前一级分组：

- **个人**
  - **常规**：当前显示占位页面。
  - **外观**：调整界面字体与字号。
- **集成**
  - **服务**：管理已接入的代理服务。

窗口底部提供 `确定` / `取消` 两个按钮：

- `确定`：保存当前修改并关闭窗口。
- `取消`：放弃修改并关闭窗口。

修改后的设置存储在本地用户目录下，下次启动时自动恢复。

## 外观

控制整个应用的字体与字号。默认 UI 字体使用系统字体链 `SimHei, Segoe UI, Microsoft YaHei UI, Microsoft YaHei`，让桌面端优先按黑体渲染中文，同时保持英文与系统控件观感稳定。修改后需要重启应用或重开受影响的视图才能完整生效。

> 已有本地配置若仍保存旧的 UI 字体值，应用会在加载设置时自动迁移到上面的系统字体链，无需手动调整。

| 项 | 说明 |
|---|---|
| UI 字体 | 应用界面使用的主字体 |
| 代码字体 | 聊天与差异视图中代码使用的字体 |
| UI 字号 | 应用界面使用的基础字号（像素） |
| 代码字号 | 聊天与差异视图中代码使用的基础字号（像素） |

字号项可输入整数值。

## 服务

以服务卡片形式展示当前可用的代理集成。

### OpenCode

显示 OpenCode 集成状态并提供连接配置：

- **启用开关**：开启后自动连接并复用当前客户端。
- **url**：当前连接地址（由 `Host:Port` 自动生成，只读）。
- **username**：连接服务时使用的账号。
- **password**：连接服务时使用的密码；点击右侧眼睛按钮可显示或隐藏明文。
- **状态**：显示 `已连接` 或 `断开`。

> 关闭启用开关后，状态会立即显示为 `断开`，再次开启时会自动重新尝试连接。
